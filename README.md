# Satwik Enterprise — Vite + React + TypeScript

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Main files

- `src/App.tsx` — page structure, content and components
- `src/styles.css` — responsive styling
- `src/main.tsx` — React entry point
- `index.html` — document shell

The supplied design uses remote image URLs as placeholders. Replace them with your own factory/product images for the final website.
